Connect your Oura Ring

This dashboard pulls all available daily metrics directly from the Oura API v2.

1. Get your Personal Access Token
Open Oura Cloud → Personal Access Tokens
If the page says tokens are deprecated, create an OAuth application instead and use the access token.
2. Set your token
# .env file (recommended)
OURA_TOKEN=your_token_here
OURA_DAYS=14
Then restart uvicorn (it reads .env on startup)
